# 메타 광고 실전 검증 — 오지렌 라벨프린터 핑크

수업 과제: 예산 5만 원으로 메타 광고를 실제 고객에게 집행하고 CTR·CVR을 측정한다.
전환 정의는 **랜딩페이지의 「구매하기」 버튼 클릭**이다(쿠팡 실구매는 필요 없음).

- 상품: https://www.coupang.com/vp/products/8113159630 (19,900원, 별점 4.8, 리뷰 8,293개 — 2026-10-30 기준)
- 랜딩페이지: `index.html` (정적 단일 파일, 모바일 우선)
- 광고 소재: `creatives/ad-A-parenting.png`(A안 육아), `creatives/ad-B-organizing.png`(B안 정리정돈) — 원본은 `creatives.html`

## 측정 설계

| 이벤트 | 시점 | 쓰임 |
|---|---|---|
| `PageView`, `ViewContent` | 랜딩 진입 | CVR 분모 확인용 |
| `InitiateCheckout` | 「구매하기」 클릭(페이지당 1회) | **전환 = CVR 분자** |
| `BuyClick`(맞춤, `position`=hero/sticky/bottom) | 같은 클릭 | 어느 버튼이 눌렸는지 |

- **CTR(링크)** = 링크 클릭 ÷ 노출 — 광고 관리자가 자동 계산
- **CVR** = `InitiateCheckout` ÷ 랜딩 페이지 조회 — 광고 관리자 열에 「결제 시작」과 「랜딩 페이지 조회」를 추가해서 계산
- 참고로 링크 클릭 기준 CVR(결제 시작 ÷ 링크 클릭)도 같이 적는다. 클릭 후 페이지 로딩 전 이탈이 있어 두 값이 다르다.
- 쿠팡 파트너스 링크를 쓰면 파트너스 리포트의 실구매액으로 ROAS = 구매액 ÷ 광고비도 낼 수 있다.

## 실행 순서

1. **픽셀 만들기**: business.facebook.com → 이벤트 관리자 → 데이터 소스 연결 → 웹 → 픽셀 생성. 숫자 ID를 `index.html`의 `PIXEL_ID`에 넣는다.
2. **(선택) 쿠팡 파트너스**: partners.coupang.com 가입 → 상품 링크 생성 → `BUY_URL`에 `https://link.coupang.com/...` 링크를 넣으면 대가성 문구가 자동으로 표시된다.
3. **배포**: GitHub Pages 등 HTTPS 정적 호스팅에 올린다.
4. **픽셀 확인**: 이벤트 관리자 → 이벤트 테스트에서 배포 URL을 열고 버튼을 눌러 `PageView`·`InitiateCheckout`이 들어오는지 본다. (Chrome 확장 Meta Pixel Helper로도 확인 가능)
5. **캠페인** (광고 관리자):
   - 목표: **트래픽**, 성과 목표: **랜딩 페이지 조회수 극대화** — 새 픽셀은 전환 데이터가 없어 「판매」 목표로는 5만 원 안에서 학습이 안 끝난다.
   - 예산: 광고 세트 1개, **일 10,000원 × 5일 = 50,000원** (총예산 50,000원 + 종료일 지정도 가능)
   - 타깃: 대한민국, 25~44세, Advantage+ 타깃(관심사 제안: 육아·어린이집·정리정돈·살림). 노출 위치는 Advantage+.
   - 광고 2개(A안·B안)를 같은 세트에 넣어 소재 A/B를 비교한다. 각 URL 끝에 `?utm_content=A` / `?utm_content=B`.
   - 문구 예시 — A: 「어린이집 준비물 이름표, 폰으로 쓰고 3초 만에 뽑으세요. 잉크 없는 감열식이라 유지비 걱정도 없어요.」 / B: 「반찬통 날짜, 약통 복용법, 서랍 정리까지. 라벨 하나로 집 정리가 끝나요.」 / CTA 버튼: 「더 알아보기」
6. **집행 중**: 하루 1번 광고 관리자에서 노출·클릭·CTR·결제 시작을 기록한다. 3일째 CTR이 확실히 낮은 소재는 꺼도 된다.
7. **결과 정리**: 노출, 링크 클릭, CTR, CPC, 랜딩 페이지 조회, 결제 시작, CVR, (파트너스 시) 구매액·ROAS.

## 예상치 (검증 전 가설)

CPC 300~600원 → 링크 클릭 80~160회, CTR 1~2%, CVR 10~25%. 실측과 비교해서 발표에서 다룬다.
